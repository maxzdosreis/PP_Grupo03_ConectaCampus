|---|---|
| **Estado da decisão** | Decidida. Resposta do professor na Aula 7 (06/11/2026), que confirma a convenção já usada; nenhum CR. |
| **Pergunta** | Nas fichas de caso de uso, as exceções são numeradas com `E` (como sugere A3·s12: `A3` / `E5`) ou tudo fica como `A` (como A3·s15 numera uma exceção, `A2.2`)? |
| **Resposta do professor** | "Pode ser assim sim." (sobre `A` para alternativas e `E` para exceções) |
| **Decisão** | Alternativas numeradas com `A` e exceções com `E`, ligadas ao passo (`A3.1`, `E9.1`), como nas fichas de caso de uso desde a REQ-04 ([decisão i](../casos-de-uso/README.md#decisao-i)). Nada muda. |
| **Responsável** | Professor (resposta); grupo (decisão). |
| **Prazo** | Decidida em 06/11/2026. |
| **Artefatos afetados** | [Fichas de caso de uso](../casos-de-uso/README.md#fichas-dos-casos-de-uso) (IDs `A` e `E`); coluna UC da [matriz](../rastreabilidade/matriz.md); campo Origem dos CAs. · **REQ-06:** nenhuma história depende desta decisão; 0 critérios de aceite e 0 testes de aceite a rever ([mapa de impacto](../rastreabilidade/impacto-por-dec.md#dec-14)). |
| **Origem** | Ponto a confirmar 5 de `.claude/requisitos.md` ([pauta da Aula 7](pauta-aula-7.md#pontos-a-confirmar)). |
