# Catálogo regra → teste: espaços (ESP-06)

> Evidência para a rastreabilidade da disciplina de Requisitos (REQ-06): cada regra de negócio de espaços aponta para onde está implementada e para os testes que a provam. **Este catálogo muda junto com os testes**: um teste renomeado, removido ou acrescentado em `src/backend/espacos/tests/` atualiza a linha correspondente aqui.

Caminhos de código relativos a `src/backend/espacos/`; testes em `src/backend/espacos/tests/`, salvo indicação. `[x]` = um teste parametrizado (vários casos).

**Tipos de teste:**

- **Unitário:** domínio puro, sem banco.
- **Caso de uso:** `application/` com o fake em memória.
- **Propriedade:** Hypothesis, com centenas a milhares de entradas geradas.
- **Contrato:** o mesmo teste contra o repositório Django e contra o fake.
- **API:** `APIClient`, com banco.
- **Concorrência:** duas threads de verdade.
- **Matriz:** `config/tests/test_matriz_de_acesso.py`, login JWT de verdade.
- **Mutação:** a regra está em `domain/` ou `application/` e o mutmut não deixa sobrevivente sem justificativa.

- Ele só muta código **dentro de funções**. Não muta constantes de módulo (`NOME_MAXIMO_CARACTERES`, `CAPACIDADE_MINIMA`), atributos de classe (`codigo`, `mensagem_padrao`, `campo`) nem `_TIPOS_ACEITOS`; esses ficam provados pelos testes que conferem código e mensagem completos (por exemplo, `test_tipo_desconhecido_e_recusado_listando_os_tipos_aceitos` agora compara a mensagem inteira).
- Ele não muta funções com decorador (as `@property`).

## 4. Observação: fake × PostgreSQL em letras especiais

O fake compara nomes com `str.casefold()`. O banco usa `Lower("nome")` na constraint e `nome__iexact` (`UPPER`) na consulta. Para quase todo texto os três concordam, mas não para letras como `ß`: `"ß".casefold() == "ss"`, enquanto no PostgreSQL `lower('ß')` continua `ß`. A propriedade de nome único roda contra o fake e usa a regra dele. No banco, a constraint continua sendo a garantia final, e o repositório traduz a violação para a mesma `NomeDeEspacoJaCadastrado`. Nenhuma mudança de produção foi feita por isso.
